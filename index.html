                        Guide d'utilisation
                    

                    
                


                
                

                    

                        Cet outil allie la rapidité d'écriture du code source
                        (façon Graphviz/Mermaid) avec la flexibilité d'un outil
                        de dessin interactif, tout en produisant une typographie
                        mathématique parfaite grâce à LaTeX.
                    


                    

                        

                            1. Syntaxe et Transitions
                        

                        

                            Pour créer des états et les relier, utilisez une
                            flèche ->.
                        

                        
Idle -> GenLow
GenLow -> GenLow

                    


                    

                        

                            2. État Initial (Reset)
                        

                        

                            Utilisez [*] pour générer un petit
                            point noir discret symbolisant le début du graphe.
                        

                        
[*] -> Idle : $\text{Reset}$

                    


                    

                        

                            3. Étiquettes avec formules LaTeX
                        

                        

                            Ajoutez un deux-points : après votre
                            transition, puis encadrez votre formule mathématique
                            avec des symboles dollar $.
                        

                        
    
                            
  • $\text{Reset}$ : Texte normal
    • 
                            
  • 
                                $\overline{GO}$ : Négation logique
                            
    • 
                            
  • 
                                $\land$ / $\lor$ : Symboles
                                logiques "ET" (\land) et "OU" (\lor)
                            
    • 
                        

                        
GenHigh -> Done : $\overline{GO} \land \text{CPT\_DONE}$

                    


                    

                        

                            4. Manipulation visuelle (Drag & Drop)
                        

                        
    
                            
  • 
                                Déplacer : Cliquez et glissez
                                les bulles.
                            
    • 
                            
  • 
                                Tordre les flèches : Passez la
                                souris sur une ligne (elle devient bleue) puis
                                glissez pour courber la flèche.
                            
    • 
                            
  • 
                                Déplacer les étiquettes :
                                Glissez directement le texte blanc pour le
                                décaler de sa flèche.
                            
    • 
                            
  • 
                                Naviguer (Pan) : Glissez le
                                fond de l'écran pour vous déplacer.
                            
    • 
                        

                    


                    

                        

                            5. Magie de l'Export PNG
                        

                        

                            Le bouton Exporter PNG cache
                            discrètement votre code source
                            à l'intérieur de l'image. Utilisez
                            Charger PNG avec cette image pour
                            retrouver instantanément votre graphe complet,
                            modifiable avec la position exacte des éléments !
