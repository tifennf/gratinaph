Comment créer votre graphe ?

Cet outil a été conçu pour allier la rapidité d'écriture du code source (façon Graphviz/Mermaid) avec la flexibilité d'un outil de dessin interactif, tout en produisant une typographie mathématique parfaite grâce à LaTeX.

1 Syntaxe de base et Transitions

Pour créer des états et les relier, utilisez simplement une flèche ->. L'outil créera automatiquement les bulles correspondantes si elles n'existent pas.

// Syntaxe : ÉtatSource -> ÉtatCible
Idle -> GenLow
GenLow -> GenLow

2 L'état initial (Reset global)

Pour symboliser le point d'entrée de votre système (le moment où la machine s'allume), utilisez la syntaxe spéciale [*]. Cela générera un petit point noir discret.

// Fait apparaître une flèche depuis "nulle part" vers Idle
[*] -> Idle

3 Étiquettes avec formules LaTeX

Ajoutez un deux-points : après votre transition, puis encadrez votre formule mathématique avec des symboles dollar $.

$\text{Reset}$
Affiche du texte normal (non italique).
$\overline{GO}$
Ajoute une barre de négation au-dessus (Not GO).
$\land$ / $\lor$
Symboles logiques "ET" (\land) et "OU" (\lor).
$A_{1} + B^{2}$
Indices et exposants classiques.
Idle -> GenLow : $GO$
GenHigh -> Done : $\overline{GO} \land \text{CPT\_DONE}$

Note : Si vous utilisez l'underscore _ pour du texte (comme CPT_DONE), pensez à l'échapper en LaTeX avec un antislash : \_, sinon LaTeX l'interprétera comme un indice !

4 Coloration des états

Personnalisez le fond de vos bulles avec le mot-clé color, suivi du nom de l'état, puis d'un code couleur Hexadécimal ou d'un nom de couleur web (red, lightblue...).

color Idle #a7f3d0
color Done pink

Manipulation visuelle du graphe

🖐️
Déplacer les états : Cliquez et glissez n'importe quelle bulle (y compris le point initial). Les flèches s'adapteront automatiquement avec des calculs trigonométriques pour s'arrêter parfaitement sur les bords.
➰
Tordre les flèches : Passez votre souris sur la ligne d'une flèche (elle deviendra bleue et épaisse). Cliquez et glissez pour modifier la courbure de la flèche afin d'éviter les croisements disgracieux.
🏷️
Déplacer les étiquettes : Si un texte LaTeX chevauche une autre ligne, attrapez directement l'étiquette (le texte avec le fond blanc) et déplacez-la. Elle glissera indépendamment de sa flèche d'origine !
🗺️
Naviguer dans l'espace (Pan) : Cliquez n'importe où sur le fond pointillé gris et glissez pour déplacer l'ensemble de la caméra. Utile si votre diagramme devient très grand.

Sauvegarde et Export "Magique"

1. La sauvegarde automatique silencieuse

Vous n'avez (presque) rien à faire. À chaque fois que vous tapez une lettre ou que vous relâchez votre souris après un déplacement, l'outil sauvegarde tout dans votre navigateur. Même si vous fermez l'onglet par accident, vous retrouverez votre travail en revenant sur la page. Vous pouvez aussi utiliser Ctrl + S pour forcer la sauvegarde et vous rassurer.

2. L'export PNG Stéganographique (La magie)

Le bouton Exporter PNG ne génère pas qu'une simple image HD de votre graphe. Il cache discrètement tout le code source, les couleurs et les positions exactes de vos flèches à l'intérieur du fichier image (sans altérer l'image !).

Pour reprendre un vieux travail : Utilisez simplement le bouton Charger PNG, sélectionnez l'image que vous aviez exportée par le passé, et l'éditeur restaurera instantanément votre code source et l'emplacement exact de chaque bulle et flèche !
